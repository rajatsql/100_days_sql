# 🚀 100 Days of SQL

**100 Days • 5 SQL Problems Every Day • 500 SQL Problems**

A 100-day SQL challenge focused on improving SQL problem-solving, query writing, pattern recognition, interview preparation, and real-world SQL skills.

## 🎯 Challenge Goals

- Solve **5 SQL problems every day**
- Complete **500 SQL problems in 100 days**
- Improve SQL problem-solving and query-writing skills
- Understand common SQL patterns
- Practice interview-oriented SQL problems
- Work on real-world SQL scenarios
- Learn from mistakes and improve accuracy
- Build a permanent SQL revision repository
